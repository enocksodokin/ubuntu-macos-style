# Projets tiers

Ce repo **ne contient pas** leur code : `install.sh` les télécharge depuis leurs sources officielles,
à une version précise. Chacun garde sa propre licence.

| Projet | Source | Version |
|---|---|---|
| WhiteSur GTK / icônes / curseurs / fonds | github.com/vinceliuice | commits épinglés dans `install.sh` |
| Lintel | github.com/eliotBenitez/lintel | v0.17.2 |
| Dash to Dock | extensions.gnome.org | dernière compatible |
| Blur my Shell | github.com/aunetx/blur-my-shell | dernière compatible |
| Compiz windows effect / Magic lamp | github.com/hermes83 | dernière compatible |
| Desktop Cube | github.com/Schneegans/Desktop-Cube | dernière compatible (+ petit correctif GNOME 50 dans `patches/`) |
| Desktop widgets | github.com/r3nhick/desktop-widgets | commit 03c677f |

Le dossier `extensions/` contient mes trois extensions (licence MIT, voir `LICENSE`).
Les correctifs de `patches/` sont appliqués localement à la copie téléchargée, jamais redistribués.
